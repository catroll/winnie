# Winnie

具备长期记忆能力的通用 AI 智能体，通过 OpenAI 兼容的 Chat Completions 接口对外服务。交互经语义提炼后写入向量库，以检索增强生成（RAG）实现个性化记忆。

更多设计说明见 [DESIGN.md](./DESIGN.md)。
